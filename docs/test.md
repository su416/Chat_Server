# ChatServer 测试记录

## 1. 测试目的

对 ChatServer 的核心业务链路进行回归验证，确认服务端、命令行客户端与 Qt 图形客户端能够协同工作，并验证常见异常场景下的行为是否符合预期。

---

## 2. 测试环境

| 项目 | 说明 |
|------|------|
| 操作系统 | Ubuntu 24.04 |
| 编译器 | g++ 13.3.0 |
| 构建工具 | CMake |
| 数据库 | MySQL 8.x |
| 缓存 / 消息转发 | Redis 7.x |
| 服务端 | ChatServer |
| 客户端 | 命令行客户端、Qt 客户端 |
| 网络环境 | 本机回环地址 `127.0.0.1:6000` |

---

8. 已知边界
当前协议主链路仍以 JSON 为主，Protobuf 仍处于逐步接入阶段
当前测试以手工回归验证为主，尚未引入自动化测试框架
当前未进行系统化压力测试，仅完成功能与异常场景验证
Qt 客户端目前以功能验证和项目展示为主，界面视觉效果仍有优化空间
9. 结论

当前项目核心业务链路已经完整打通：

服务端可稳定处理登录、好友关系、群组关系、单聊、群聊、历史消息与注销
命令行客户端功能可用
Qt 图形客户端功能完整，可用于项目展示
基础功能与常见异常场景均已验证通过
